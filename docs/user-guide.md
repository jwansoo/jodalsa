# 조달컨설팅 사용설명서

공공조달관리사 자격시험 준비를 위한 모의고사, 문제모음, 수험교재, 시험결과분석, 문의하기 기능을 제공하는 서비스입니다. 이 문서는 각 화면의 사용 방법을 안내합니다.

## 1. 회원가입 및 로그인

- 홈 화면 상단의 **회원가입** 버튼을 눌러 사용자명, 이름, 성, 이메일, 비밀번호를 입력하면 계정이 생성됩니다. 비밀번호는 6자 이상이어야 합니다.
- 이미 계정이 있다면 **로그인** 버튼을 눌러 이메일과 비밀번호로 로그인합니다.
- 로그인하지 않은 상태에서는 홈 화면과 회원가입/로그인 화면만 볼 수 있고, 그 외 메뉴(문제모음, 모의고사, 수험교재 등)는 로그인 후에 이용할 수 있습니다. 단, 홈 화면의 **1회차 모의고사 무료체험**은 로그인 없이도 풀어볼 수 있습니다.
- 로그아웃은 왼쪽 사이드바 하단의 **로그아웃**을 클릭하면 됩니다.

## 2. 화면 구성

- **왼쪽 사이드바**: 홈 / 문제모음 / 모의고사 / 수험교재 메뉴가 있고, 관리자 계정으로 로그인하면 그 아래에 문의관리와 사용설명서 메뉴가 추가로 보입니다.
  - 사이드바 상단의 ☰ 버튼으로 사이드바를 접거나 펼칠 수 있습니다.
  - **+** 버튼을 누르면 새 예상문제를 등록하는 창이 열립니다.
- **상단 바**: 검색창, 사용자 아이콘(내 프로필 · 시험결과분석 바로가기), 화면 우측 상단의 달/해 아이콘으로 다크 모드와 라이트 모드를 전환할 수 있습니다.
- **홈 화면 우측 하단의 말풍선 아이콘**: 문의하기 채팅창을 열고 닫습니다.

## 3. 홈 화면

- 서비스 소개와 함께 **모의고사**, **수험교재** 바로가기 카드가 있습니다.
- **1회차 모의고사 무료체험**: 로그인 없이도 1회차 모의고사를 체험할 수 있습니다. 로그인한 상태로 풀면 결과가 저장되어 나중에 시험결과분석에서 다시 확인할 수 있습니다.
- 궁금한 점은 우측 하단 채팅 아이콘을 눌러 이름(및 연락처, 선택)과 메시지를 남기면 관리자가 답변을 남겼을 때 같은 창에서 실시간으로 확인할 수 있습니다.

## 4. 문제모음 (예상문제 은행)

사이드바의 **문제모음**을 클릭하면 등록된 예상문제 전체 목록이 표 형태(일련번호 · 분류 · 세부분류 · 문제)로 표시됩니다.

- 문제 열 상단의 검색창에 키워드를 입력하면 해당 문제만 걸러서 볼 수 있습니다.
- 문제 내용을 클릭하면 상세 화면으로 이동하며, 분류 · 세부분류 · 질문 · 보기(가~라) · 정답 · 해설 항목을 각각 클릭해 바로 수정할 수 있습니다. 수정 후 다른 곳을 클릭하거나 Enter를 누르면 저장되고, Esc를 누르면 수정을 취소합니다.
- 새 문제를 추가하려면 사이드바 상단의 **+** 버튼을 눌러 분류 · 세부분류 · 질문 · 보기 · 정답 · 해설 · 주석을 입력한 뒤 등록합니다.

## 5. 모의고사

사이드바의 **모의고사**를 클릭한 뒤 상단에서 응시할 회차(1~10회차)를 선택하면 시험이 시작됩니다.

- 실제 시험과 동일하게 **1교시(30문항) · 2교시(20문항) · 3교시(30문항)**, 총 120분(문항 수에 비례하여 교시별 시간 배분)로 진행됩니다.
- 각 교시 진행 중에는 화면 오른쪽 위에 남은 시간이 표시됩니다. 시간을 클릭하면 일시정지/재개할 수 있고, 시간이 다 되면 해당 교시는 자동으로 제출되고 다음 교시로 넘어갑니다.
- 마지막 교시까지 제출하면 **합격/불합격** 결과가 표시됩니다. 합격 기준은 과목(교시)당 40점 이상, 전 과목 평균 60점 이상입니다.
- 결과 화면에서 **시험결과 보기**를 누르면 문제별로 내가 선택한 답과 정답을 비교해 볼 수 있고, **시험결과분석**을 누르면 취약한 과목과 세부 분야, 미응답 문항 수를 알려주는 분석 내용을 볼 수 있습니다.
- 로그인한 상태로 응시하면 결과가 자동 저장됩니다. 같은 회차를 다시 응시하면 이전 결과는 최신 결과로 갱신됩니다.

## 6. 시험결과분석

상단 바의 사용자 아이콘을 눌러 **시험결과분석**을 선택하면, 지금까지 응시하고 저장된 모든 회차의 결과를 한 번에 볼 수 있습니다. 회차별로 교시별 점수, 평균, 합격/불합격 여부와 저장된 분석 내용이 표시됩니다.

## 7. 수험교재

사이드바의 **수험교재**를 클릭하면 그 바로 아래에 시험 범위 목차(대분류 · 세부분류)가 트리 형태로 펼쳐집니다.

- 대분류를 클릭하면 하위 세부분류 목록이 펼쳐지거나 접힙니다.
- 세부분류 항목을 클릭하면 해당 자료(PDF)가 화면 안의 뷰어 창에서 바로 열립니다. 파일이 외부 프로그램이나 다른 사이트로 열리지 않고, 페이지를 아래로 스크롤하며 전체 내용을 이어서 볼 수 있습니다.
- 뷰어 상단의 돋보기(+/−) 버튼으로 화면을 확대/축소할 수 있습니다. 저작권 보호를 위해 다운로드·인쇄 기능은 제공하지 않습니다.

## 8. 프로필

상단 바의 사용자 아이콘 → **프로필**을 클릭하면 내 사용자명, 이름, 소개글을 확인할 수 있습니다.

## 9. 문의관리 (관리자 전용)

관리자 계정(`is_admin`)으로 로그인하면 사이드바에 **문의관리** 메뉴가 나타납니다.

- 문의관리 목록에서 방문자별 문의 스레드를 확인할 수 있습니다.
- 문의를 클릭하면 대화 내용을 확인하고 답변을 입력해 보낼 수 있습니다. 답변은 방문자의 문의하기 창에 실시간으로 전달됩니다.

## 10. 화면 테마

상단 바 오른쪽의 달/해 아이콘을 클릭하면 다크 모드와 라이트 모드를 전환할 수 있습니다. 선택한 테마는 브라우저에 저장되어 다음 방문 시에도 유지됩니다.
