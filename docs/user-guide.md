# 조달컨설팅 사용설명서

공공조달관리사 자격시험 준비를 위한 모의고사, 수험교재, 이용상품구매, 시험결과분석, 문의하기 기능을 제공하는 서비스입니다. 이 문서는 각 화면의 사용 방법을 안내합니다.

## 1. 회원가입 및 로그인

- 홈 화면 상단의 **회원가입** 버튼을 눌러 사용자명, 이름, 성, 이메일, 전화번호, 비밀번호를 입력하면 계정이 생성됩니다. 비밀번호는 6자 이상이어야 합니다. 이미 사용 중인 사용자명이면 안내 메시지가 표시됩니다.
- 이미 계정이 있다면 **로그인** 버튼을 눌러 이메일과 비밀번호로 로그인합니다.
- 로그인하지 않은 상태에서는 홈 화면과 회원가입/로그인 화면만 볼 수 있고, 그 외 메뉴(모의고사, 수험교재, 이용상품구매 등)는 로그인 후에 이용할 수 있습니다. 단, 홈 화면의 **모의고사 '무료체험'**은 로그인 없이도 풀어볼 수 있습니다.
- 로그아웃은 왼쪽 사이드바 하단의 **로그아웃**을 클릭하면 됩니다.

## 2. 화면 구성

- **왼쪽 사이드바**: 홈 / 모의고사 / 수험교재 / 이용상품구매 / 사용설명서 메뉴가 있습니다. 관리자 계정으로 로그인하면 그 위에 **문제모음** 메뉴가, 그 아래에 **문의관리**, **입금확인** 메뉴가 추가로 보입니다(자세한 내용은 12장 참고).
  - 사이드바 상단의 ☰ 버튼으로 사이드바를 접거나 펼칠 수 있습니다.
  - **+** 버튼은 새 예상문제를 등록하는 창을 여는 관리자 전용 기능으로, 관리자 계정이 아니면 비활성화되어 클릭할 수 없습니다.
- **상단 바**:
  - **검색창**: 키워드를 입력하면 사이트 메뉴, 수험교재 목차(필기·핵심규정·실기), (관리자 계정은) 문제모음 질문 내용까지 함께 검색되어 아래에 결과 목록이 표시됩니다. 결과를 클릭하면 해당 화면으로 바로 이동합니다.
  - **사용자 아이콘**을 누르면 **프로필**, **구매내역**, **시험결과분석**으로 이동할 수 있는 메뉴가 열립니다.
  - 화면 우측 상단의 달/해 아이콘으로 다크 모드와 라이트 모드를 전환할 수 있습니다.
- **화면 우측 하단의 말풍선 아이콘**: 문의하기 채팅창을 열고 닫습니다. 마우스를 올리거나 포커스를 두면 "채팅"이라는 안내가 표시됩니다.

## 3. 홈 화면

- 서비스 소개와 함께 **모의고사**, **수험교재** 바로가기 카드가 있습니다. 카드에 마우스를 올리면 "바로가기" 표시와 함께 해당 화면으로 이동할 수 있습니다.
- **모의고사 '무료체험'**: 로그인 없이 모의고사를 체험해 보세요. 로그인한 상태로 풀면 결과가 저장되어 나중에 시험결과분석에서 다시 확인할 수 있습니다.
- 궁금한 점은 우측 하단 채팅 아이콘을 눌러 이름(및 연락처, 선택)과 메시지를 남기면 관리자가 답변을 남겼을 때 같은 창에서 실시간으로 확인할 수 있습니다.

## 4. 모의고사

사이드바의 **모의고사**를 클릭한 뒤 상단에서 응시할 회차를 선택하면 시험이 시작됩니다.

- 선택 가능한 회차 목록은 **이용상품구매**에서 구매(입금 확인 완료)한 만큼만 표시됩니다. 예를 들어 "2회"를 구매했다면 1회차·2회차가 선택 가능하고, **년간이용**을 구매했다면 전체 회차가 모두 선택 가능합니다. 구매한 회차가 없으면 이용상품구매 화면으로 이동하는 안내가 표시됩니다.
- 실제 시험과 동일하게 **1교시(30문항) · 2교시(20문항) · 3교시(30문항)**, 총 120분(문항 수에 비례하여 교시별 시간 배분)으로 진행됩니다.
- 각 교시 진행 중에는 화면 오른쪽 위에 남은 시간이 표시됩니다. 시간을 클릭하면 일시정지/재개할 수 있고, 시간이 다 되면 해당 교시는 자동으로 제출되고 다음 교시로 넘어갑니다.
- 마지막 교시까지 제출하면 **합격/불합격** 결과가 표시됩니다. 합격 기준은 과목(교시)당 40점 이상, 전 과목 평균 60점 이상입니다.
- 결과 화면에서 **시험결과 보기**를 누르면 문제별로 내가 선택한 답과 정답을 비교해 볼 수 있고, **시험결과분석**을 누르면 취약한 과목과 세부 분야, 미응답 문항 수를 알려주는 분석 내용을 볼 수 있습니다.
- 로그인한 상태로 응시하면 결과가 자동 저장됩니다. 같은 회차를 다시 응시하면 이전 결과는 최신 결과로 갱신됩니다.

## 5. 수험교재

사이드바의 **수험교재**를 클릭하면 필기 · 핵심규정 · 실기 세 항목이 있는 화면으로 이동합니다.

- **필기**는 대분류를 클릭하면 하위 세부분류 목록이 펼쳐지거나 접히는 트리 형태로 표시됩니다. **핵심규정**, **실기**는 목록 형태로 표시됩니다.
- 각 항목은 **이용상품구매**에서 구매(입금 확인 완료)한 것만 열람할 수 있습니다. 구매하지 않은 항목은 "(구매 필요)" 표시와 함께 이용상품구매로 이동하는 안내가 나타납니다. **년간이용**을 구매하면 세 항목 모두 이용할 수 있습니다.
- 이용 가능한 세부분류 항목을 클릭하면 해당 자료(PDF)가 화면 안의 뷰어 창에서 바로 열립니다. 파일이 외부 프로그램이나 다른 사이트로 열리지 않고, 페이지를 아래로 스크롤하며 전체 내용을 이어서 볼 수 있습니다.
- 뷰어 상단의 돋보기(+/−) 버튼으로 화면을 확대/축소할 수 있습니다. 저작권 보호를 위해 다운로드·인쇄 기능은 제공하지 않습니다.

## 6. 이용상품구매

사이드바의 **이용상품구매**를 클릭하면 상품을 선택하고 신청하는 화면으로 이동합니다.

- **선택이용**: 모의고사 회차 수(1~10회, 1회당 2만원 — 선택 시 1회차부터 해당 회차까지 이용 가능)와 수험교재(필기 10만원 · 핵심규정 5만원 · 실기 5만원, 복수 선택 가능)를 자유롭게 조합해 선택할 수 있으며, 결제 금액은 선택한 항목의 합계로 계산됩니다.
- **년간이용**: 40만원 정액으로 모의고사 전 회차와 수험교재(필기·핵심규정·실기)를 12개월간 모두 이용할 수 있습니다.
- 결제 안내에 따라 **국민은행 803501-00-153698 (예금주: 장완수(조달컨설팅))** 계좌로 입금자명을 입력한 뒤 **신청하기**를 누르면 신청이 접수됩니다.
- 카드 결제(PG) 기능은 준비 중이며, 그 전까지는 계좌이체로만 결제할 수 있습니다.
- 입금 후에는 전화(010-8625-5197)로 **'입금했다'**라고 메시지를 남겨주시면 확인 후 바로 상품이용이 가능합니다. 또는 홈 화면 우측 하단 채팅창에 **'입금했다'**라고 남겨주셔도 됩니다. 관리자가 입금을 확인해 처리하면 모의고사·수험교재에서 구매한 항목을 바로 이용할 수 있습니다.

## 7. 구매내역

상단 바의 사용자 아이콘 → **구매내역**을 선택하면 지금까지 신청한 상품의 신청일시, 상품 내용, 금액, 처리 상태(입금대기 / 이용가능 / 취소됨)를 확인할 수 있습니다.

## 8. 시험결과분석

상단 바의 사용자 아이콘을 눌러 **시험결과분석**을 선택하면, 지금까지 응시하고 저장된 모든 회차의 결과를 한 번에 볼 수 있습니다. 회차별로 교시별 점수, 평균, 합격/불합격 여부와 저장된 분석 내용이 표시됩니다.

## 9. 프로필

상단 바의 사용자 아이콘 → **프로필**을 클릭하면 내 사용자명, 이름, 소개글을 확인할 수 있습니다. **프로필 수정** 버튼을 누르면 사용자명·이름·소개글을 바로 수정할 수 있으며, 이미 사용 중인 사용자명으로는 변경할 수 없습니다.

프로필, 구매내역, 시험결과분석 화면 맨 아래에는 **홈으로 가기** 링크가 있어 클릭하면 바로 홈 화면으로 이동합니다.

## 10. 화면 테마

상단 바 오른쪽의 달/해 아이콘을 클릭하면 다크 모드와 라이트 모드를 전환할 수 있습니다. 선택한 테마는 브라우저에 저장되어 다음 방문 시에도 유지됩니다.

## 11. 관리자 전용 기능

관리자 계정(`is_admin`)으로 로그인하면 사이드바에 아래 메뉴가 추가로 나타납니다.

- **문제모음**: 등록된 예상문제 전체 목록이 표 형태(일련번호 · 분류 · 세부분류 · 문제)로 표시됩니다. 문제 열 상단의 검색창에 키워드를 입력하면 해당 문제만 걸러서 볼 수 있고, 문제 내용을 클릭하면 상세 화면에서 분류 · 세부분류 · 질문 · 보기(가~라) · 정답 · 해설 항목을 각각 클릭해 바로 수정할 수 있습니다(수정 후 다른 곳을 클릭하거나 Enter를 누르면 저장, Esc를 누르면 취소). 사이드바 상단의 **+** 버튼을 누르면 새 문제를 등록하는 창이 열립니다.
- **문의관리**: 방문자별 문의 스레드 목록을 확인하고, 클릭하면 대화 내용을 확인하고 답변을 입력해 보낼 수 있습니다. 답변은 방문자의 문의하기 창에 실시간으로 전달됩니다.
- **입금확인**: 이용상품구매를 통해 접수된 신청 내역을 신청일시 · 사용자 · 상품 · 금액 · 입금자명 · 상태별로 확인할 수 있습니다. 입금을 확인한 뒤 **입금확인 처리** 버튼을 누르면 해당 사용자가 구매한 모의고사 회차·수험교재를 바로 이용할 수 있게 됩니다.
